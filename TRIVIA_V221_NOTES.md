# Trivia Polish v2.21

## Connected Supabase
The Supabase project now reports 183 active Trivia questions grouped in 78 topics, difficulty levels 1–5. The server chooses one question per level, prefers different topics/categories, and limits recently seen practice questions where there are sufficient fresh alternatives. Daily uses a shared question set. The public repository carries no correct-answer database.

## Forbidden Intel
Third reward unlocks after completing ranked Daily Trivia, regardless of score. The completed status is cached in this browser; if moving devices, start/resume Daily Trivia to sync the completion. Existing Full Scan and One Signal unlocks remain unchanged.

## Art
No actual transparent full-body image set is bundled for the 10 requested characters; the game retains existing authentic source art. Producing consistent full-body renderings requires vetted source images for each legend.
